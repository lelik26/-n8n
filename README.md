## 🤖 AI-ассистенты и чат-боты

### 1. 🏠 Home Bot — AI-помощник с генерацией изображений и поддержкой голоса
**Тип:** Telegram-бот с векторной базой данных  
**Задача:** Автоматизация ответов на вопросы клиентов с использованием корпоративной базы знаний

#### 📊 Функционал:
- ✅ Обработка текстовых запросов
- ✅ Распознавание и обработка голосовых сообщений (Whisper API)
- ✅ Вебпоиск по запросу
- ✅ Контекстные ответы 
- ✅ Генерация изображений
- ✅ Создание контекста

#### 🛠️ Технологический стек:
```
Платформа:     n8n workflow automation
AI/ML:         | OpenAI GPT 5 nano | Imagen 1.5 OpenAI | Trascribe audio |
Хранилище:     Simple Memory |
Мессенджер:    Telegram Bot API
```

#### 📈 Результаты:
- **70% запросов** обрабатываются без участия человека
- **24/7 доступность** поддержки
- Время ответа **<5 секунд**
- Поддержка **текста и голоса**

#### 🔗 Документация:
- [Подробное описание и Схема workflow](./Home_Bot/home_bot.md)

### 2. 🎓 Personal Mentor — Персональный ментор для обучения
**Тип:** Telegram-бот для создания учебных планов и контента  
**Задача:** Автоматизация процесса обучения сотрудников с персонализированными планами

#### 📊 Функционал:
- ✅ Создание индивидуальных учебных планов на основе темы и уровня
- ✅ Генерация образовательного контента с актуальной информацией
- ✅ Поиск релевантных материалов в интернете (Tavily Search)
- ✅ Пошаговая отправка обучающих постов
- ✅ Отслеживание прогресса обучения в базе данных
- ✅ Адаптация под уровень подготовки (Junior/Middle/Senior)

#### 🛠️ Технологический стек:
```
Платформа:     n8n workflow automation
AI/ML:         OpenAI GPT-5 mini, LangChain Agents
Поиск:         Tavily Search API
База данных:   n8n Data Tables,(можно настроить Supabase,PostgreSQL) 
Мессенджер:    Telegram Bot API
```

#### 📈 Результаты:
- **Снижение нагрузки на HR на 60%**
- План обучения создается за **10 минут**
- **Автоматическая** отправка материалов
- **100% персонализация** под пользователя

### 3. 💻 CodeLowBot — Помощник по программированию на C
**Тип:** Telegram-бот для обучения программированию  
**Задача:** Помощь в изучении основ языка C с генерацией примеров кода

#### 📊 Функционал:
- ✅ Ответы на вопросы по программированию на C
- ✅ Генерация примеров кода с комментариями
- ✅ Объяснение концепций программирования
- ✅ Создание готовых программ по описанию
- ✅ Отправка кода в виде текстовых файлов
- ✅ Память диалога (25 последних сообщений)

#### 🛠️ Технологический стек:
```
Платформа:     n8n workflow automation
AI/ML:         Google Gemini 2.5 Flash, LangChain Memory
База данных:   Buffer Window Memory (25 messages)
Мессенджер:    Telegram Bot API
Парсер:        Structured Output Parser (JSON)
```

#### 📈 Результаты:
- **Помощь 100+ студентам**
- Ответ генерируется за **10-15 секунд**
- **Структурированный вывод** (код + комментарии + пояснения)
- **Контекстные ответы** с учетом истории диалога

## 🛠️ Используемые технологии (общий стек)

### 🤖 AI & Machine Learning
- **OpenAI GPT-4 / GPT-5** — основная LLM для генерации контента
- **Google Gemini 2.5 Flash** — альтернативная LLM
- **Claude (Anthropic)** — для специфических задач
- **OpenAI Whisper** — распознавание речи
- **OpenAI DALL-E 3/IMagen 1.5** — генерация изображений
- **OpenAI Embeddings** — векторизация текста
- **LangChain** — фреймворк для AI-агентов

### 🔍 Поиск и RAG
- **Tavily Search API** — поиск в интернете
- **Pinecone** — векторная база данных
- **Supabas** — векторная база данных
- **RAG (Retrieval-Augmented Generation)** — поиск по документам

### 💾 Базы данных и хранилища
- **Google Sheets** — таблицы и отчеты
- **Google Docs** — документы
- **Google Drive** — файловое хранилище
- **Supabase (PostgreSQL)** — реляционная БД
- **Baserow** — no-code база данных
- **n8n Data Tables** — встроенное хранилище n8n

### 📱 Интеграции и сервисы
- **Telegram Bot API** — основной мессенджер
- **Google Calendar** — управление событиями
- **Gmail** — отправка email
- **Google Contacts** — управление контактами
- **HH.ru API** — парсинг вакансий
- **LinkedIn API** — профессиональная сеть

### ⚙️ Платформы автоматизации
- **n8n** — основная платформа workflow automation

### 🧰 Вспомогательные инструменты
- **HTTP Request** — работа с API
- **JSON Parser** — обработка данных
- **HTML Parser** — парсинг веб-страниц
- **PDF Parser** — извлечение текста из PDF
- **Code Node (JavaScript/Python)** — кастомная логика
